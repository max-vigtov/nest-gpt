# NestGPT

A powerful NestJS-based backend application that integrates OpenAI's GPT API for advanced AI interactions and image processing capabilities.

## 🚀 Features

- Integration with OpenAI's GPT API for AI-powered interactions
- Image processing capabilities using Sharp
- Built with NestJS framework for scalable and maintainable architecture
- TypeScript support for enhanced development experience
- RESTful API endpoints for seamless integration
- Environment-based configuration management
- Comprehensive testing setup with Jest

## 🛠️ Tech Stack

- NestJS 10.x
- TypeScript
- OpenAI API
- Sharp (Image Processing)
- Jest (Testing)
- ESLint & Prettier (Code Quality)

## 📦 Installation

```bash
npm install
```

## 🔧 Configuration

Create a `.env` file in the root directory with your OpenAI API key:

```env
OPENAI_API_KEY=your_api_key_here
```

## 🚀 Running the Application

Development mode:
```bash
npm run start:dev
```

Production mode:
```bash
npm run build
npm run start:prod
```

## 🧪 Testing

```bash
# Unit tests
npm run test

# e2e tests
npm run test:e2e

# Test coverage
npm run test:cov
```
